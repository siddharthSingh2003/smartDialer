# Diagrams

The architecture, agent state machine, and call state machine diagrams are
authored as Mermaid source directly in [`ARCHITECTURE.md`](../../ARCHITECTURE.md)
(§3.2, §4.2, §5.2) rather than duplicated here as exported PNGs — GitHub and
most Markdown viewers render Mermaid natively, so the source *is* the
diagram. This directory is reserved for anyone who wants to export static
images (e.g. `mmdc -i ARCHITECTURE.md -o docs/diagrams/`) for a context that
can't render Mermaid.
